## 🧠 The six ideas worth carrying

1. **Large digit ⟺ `T`-good convergent**, both directions in the kernel: `nearInt_convDen_le`
   (from `cfDet` + `abs_convDen_mul_sub_le : |qₚy − pₚ| ≤ 2/qₚ₊₁`) and `le_digit_of_nearInt_le`
   (from the matching LOWER bound `abs_convDen_mul_sub_ge : 1/(qₚ+qₚ₊₁) ≤ |qₚy − pₚ|`).  So the
   Diophantine form is not a strengthening of the crux — the route cannot fail for bookkeeping.
2. **The all-`q` count is the WRONG object** and the kernel says so: multiples of a very good
   denominator are good (`nearInt_mul_good`), so one digit `aₚ ≥ Tk²` contributes `k ≈ √(aₚ/T)`
   denominators against ONE unit of `blockCount` (`card_le_goodDenCount_of_large_digit`).  With
   `E[√a] > 0` the naive count is `≍ (1/√T) log Q`.  Only `goodDenCountPrim` can carry `1/T`.
   Convergents are automatically primitive (`coprime_cfNum_cfK`, from `cfDet`).
3. **Primitivity restores sparsity — to the FREE rate only.**  `gap_principle` (`Tq ≤ 4q'`) gives
   `goodDenCountPrim ≤ 1 + log Q / log(T/4)`.  Everything else in the chain is now pinned by a
   theorem (sets' size: `heuristic_sum_le`; normalization: (2); spacing: `gap_principle`), so the
   ONLY open statement is **which** scales carry a good denominator.
4. **The arithmetic of `Φ` gives a negative correlation.**  `φ` is a unit (`φ⁻¹ = φ−1`) and badly
   approximable, so `qφx = m + δ ⟹ qx = (mφ − m) + δ(φ−1)`, hence
   `nearInt_mul_ge_of_good : ‖qφx‖ ≤ 2/(Tq) → ‖qx‖ ≥ 1/(16q)` (`T ≥ 32`).  A good scale for the
   image is a BAD scale for `x`.  Corollary `digit_le_of_good_at_convergent : aᵢ(x) ≤ 32`.
   Additive target: same conclusion, no unit trick (`nearInt_mul_ge_of_good_add`, `T ≥ 16`).
5. **Good pairs exclude their own numerator.**  `mφx = m²/q + mδ/q` and `gcd(m,q)=1`, `q ≥ 2` give
   `‖mφx‖ ≥ 1/(2q)` (`nearInt_numerator_ge_of_good`).  Uses only `φ(φ−1) = 1`.
6. **New permanent infrastructure**: `cfNum` (the `p₀ = 0` numerator convention) and `cfDet`
   (`qₙpₙ₋₁ − pₙqₙ₋₁ = (−1)ⁿ`), which the repo lacked; `nearInt` with its housekeeping
   (`nearInt_add_int`, `nearInt_mul_fract`, `nearInt_ge_sub`, `nearInt_sub_le`,
   `nearInt_div_nat_ge`, `nearInt_goldenRatio_ge`).
