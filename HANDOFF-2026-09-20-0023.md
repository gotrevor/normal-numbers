## 🧠 Context to carry forward
**The route change is the real result, and it generalizes.** The kickoff (`KICKOFF-2026-09-19-dyadic-to-prefix.md`)
specified: split `[0,n)` into a head `[0, n/2^m)` plus `m` dyadic blocks `[n/2^{i+1}, n/2^i)`, bound each
block against `dyadicMean` at `N = n/2^{i+1}`, sum. I started down that and backed off: it forces an
indexed family of blocks, an endpoint-rounding argument *inside* a `Finset.sum` over `i`, and a geometric
sum `∑_i N_i ≤ n` — three separate places to fight casts.

What I used instead is the **halving chain**: `n_i = n / 2^i` (note `Nat.div_div_eq_div_mul` makes
`(n/2)/2^m = n/2^(m+1)`, so the chain is definitionally the same object the kickoff indexed over). Two
lemmas, both now in the file:

- `halving_step`: with `N = n/2` and `N ≥ N₀`, `∑_{k<n} − ∑_{k<N} = ∑_{Ico N n}`; since `n ∈ {2N, 2N+1}`
  (a one-line `omega`), that is the dyadic block `Ico N (2N)` plus **at most one** extra term. Bound
  `ε'·N + C`. *All* the rounding pain is isolated here, in a single `rcases`.
- `halving_chain`: induction on `m`, generalized in `n`, peeling the **first** halving and applying the
  IH at `n/2`. The magic: the step contributes `ε'·(n/2)` and the IH contributes `ε'·(n/2)`, and
  `(n/2) + (n/2) ≤ n` in ℕ — so the telescope is exactly `ε'·n + C·m` with **no geometric series and no
  reindexing**. This is why the chain beats the block decomposition; if you ever need the analogous
  statement for a different halving/averaging argument in this repo, reuse this shape.

Assembly is then routine: `‖∑_{k<n} F‖ ≤ ε'n + Cm + C·n/2^m`, pick `m` via `exists_pow_lt_of_lt_one`
(at `ε'/(C+1)`, so `C·2^{-m} < ε'` without needing `C > 0`), then pick `n` past three thresholds
(`2^m·N₀`, the `Cm/n < ε'` threshold, and `1`). I used `ε' = ε/4` so the three-term sum `3ε' n < ε n`
is strict without fiddling.

**Assumption I operated under:** `C ≥ 0` is derivable (`hF 0` plus `norm_nonneg`), so the statement
needed no extra hypothesis — worth remembering, since the frozen signature has no `0 ≤ C`.
