## 🧠 Context to carry forward

**Mahler proof architecture** (`src/NormalNumbers/MahlerMultiplier.lean`, module
docstring has the full sketch).  `x_n = {gⁿα}`; block `w` (value `W`, length `k`)
occurs at `n` in `m·α` iff `{m x_n} ∈ C = [W/gᵏ,(W+1)/gᵏ)`.  Suppose all `m ≤ M`
fail from `N₀` on.
- *Covering lemma* `near_rational_of_bad`: Dirichlet gives reduced `p/q`, `q ≤ gᵏ`,
  `η = qx − p`, `|η| < g⁻ᵏ`.  Multiples `m = ℓq + r` (`ℓ < L = ⌊M/q⌋`) are `q`
  arithmetic progressions of step `η` starting within `|η|` above each `j/q`
  (`sweep_pos`/`sweep_neg`; modular inverse `exists_residue_mul`).  If
  `(L−1)|η| ≥ 1/q` they hit every cell.  So bad ⇒ `(M − 2gᵏ)|η| < 1`.
- *Escape lemma* `orbit_escapes`: shadow rational `g p_n/q_n − ⌊g x_n⌋` vs the
  next bad rational: the integer `q_{n+1}(g p_n − q_n⌊g x_n⌋) − q_n p_{n+1}` has
  `|·| < (q_n + g q_{n+1})/D ≤ 1` ⇒ it is `0` ⇒ `ε_{n+1} = g ε_n` EXACTLY ⇒ unbounded.
  Needs `D ≥ (g+1)Q`, `Q = gᵏ`.
- `M = (g+3)gᵏ` ⇒ `M − 2gᵏ = (g+1)gᵏ`.  The two lost `gᵏ`'s are the slack: one from
  `⌊M/q⌋` (`qL > M − q`) and one from `L − 1` (AP spans `(L−1)η`, start point
  `s ∈ (a − 1/q, a + η)`).
