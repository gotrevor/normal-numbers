## 🔑 The four things this lap established

1. **Fact (δ) — precompactness** (`runState_entries_abs_le`).  `width = |det|/(d(c+d))` exactly;
   `denRatio := (c+d)/d` is trapped in `(1/2, 6]` along ANY run (a read is `r ↦ 1+1/(r+a−1)`,
   contracting *uniformly in the digit*; an emission moves `r` by a factor in `[1/2,2]`); `|det|`
   is conserved.  So every run state of width `≥ η` has all four entries in `[−M,M]`,
   `M = √(6|det Φ|/η)`.  No hypothesis on `x`, on `Φ`, or on normality.
   *This is the "finiteness of the predictor's range" that directive fact (α) leaves open.*

2. **The modulus of continuity is free of the width** (`minDen_sq_ge`, `abs_mob_sub_le_of_entries`).
   `|det| ≤ d(c+d)` follows from `width ≤ 1` alone, so the distortion band already gives
   `minDen ≥ √(|det Φ|/6)`; states within `ρ` entrywise have maps within `4ρ/minDen`.
   **Division of labour**: the width floor buys the BOX, the distortion band buys the NET's
   usability.  Only the first is hard.

3. **Finiteness really does beat predictability** (`varCount_finiteRange_le`) — and the union bound
   is *tight*, which is why it is not enough.  For a CF-normal `x`, ANY `σ : ℕ → MapState` with
   values in a finite `T` (it may read the whole past) satisfies
   `freq{n : Gⁿx ∈ (σ n)⁻¹(a,b)} ≤ |T|·(4D(b−a)/log 2 + 2δ)`.
   **Why it does not close the crux, quantitatively** (this is the route-decisive arithmetic):
   a net gives thickening `δ ≍ ρ` with `|T| ≍ ρ^{-3}`, so the additive term is `≍ ρ^{-2}` — it
   grows as `ρ` shrinks and the thickening swallows the target as `ρ` grows.  Nothing weaker than
   the JOINT statement (state-cell against orbit point) can work.

4. **The width floor is a height question, not a geometric one** (`width_runState_bounds`).
   `|det Φ|/(6d²) ≤ width ≤ 6|det Φ|/d²`, a read multiplies `d` by `denRatio+a−1`, an emission by
   `mob 0 ∈ [1/(b+1),1/b]`.  So `log d_n ≈ Σ_{k<n} log a_k − Σ_{m<N_n} log b_m`.
   `d_runState_ge` gives the unconditional half — `d_n ≥ √(|det Φ|/6)`, the output can never get
   AHEAD of the input — and `width_ge_of_d_le` reduces the rest to `freq{n : d_n > R} → 0`.
