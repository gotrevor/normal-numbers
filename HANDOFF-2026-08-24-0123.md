## Gotchas this session
- `Finset.card_insert_of_not_mem` → **`Finset.card_insert_of_notMem`** in
  this pin (v4.33.1); `Finset.range_succ` doesn't exist, use
  **`Finset.range_add_one`**.
- Stray stacked docstrings (`/-- A -/ /-- B -/ theorem foo`) are a **parse
  error**, not silently mis-attached — exactly one doc-comment per command.
- **`fun a => Real.log (a : ℝ)` inside `List.map` over a `List ℕ`** can
  elaborate/pretty-print through `List.flatMap`/do-notation in this pin,
  breaking `rw`/`simp only [List.map_cons]` matching. Fix: annotate the
  binder itself, `fun a : ℕ => Real.log a` (not `fun a => Real.log (a:ℝ)`)
  — avoids whatever elaboration path triggers the flatMap desugaring.
- `positivity` cannot prove `0 ≤ Real.log x` goals (needs `1 ≤ x`, not a
  positivity-shaped fact) — use `Real.log_nonneg` explicitly with a
  separate `1 ≤ x` proof, every time, don't attempt `by positivity`.
- `Real.log_prod` takes ONE explicit arg (the nonzero-hypothesis), not two
  — differs from some other `_prod` lemma shapes.
- `integral_inv_of_pos ha hb : ∫ x in a..b, x⁻¹ = log (b/a)` returns a
  **quotient** log, not a difference — split with `Real.log_div` before
  `ring`, don't try to `ring` straight through a `log(b/a)` vs `log b - log
  a` mismatch.
