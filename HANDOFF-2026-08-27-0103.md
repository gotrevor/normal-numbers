## 🧠 Context to carry forward

Item 3's route (worked out by the prior session, executed this session)
was **Baire category, not probability**: build a residual set of reals that,
for every base `b` and cofinally many depths `p`, carry a periodic balanced
block (`0,1,…,b-1,0,1,…`, not a zero-run — zero-runs make TV *worse*, this
was the prior session's key correction) right after the digit prefix. This
gives a `digitTV` bound of `2/(1+b·p)` via the already-proved
`digitTV_le_periodic_sq`, and the Baire witness lands in `(0,1)` for free
(via `Dense.inter_open_nonempty` against `Set.Ioo 0 1`), sidestepping a
sign hypothesis that would otherwise need separate handling.

Two mathlib gotchas hit and fixed this session (worth remembering if this
pattern recurs elsewhere in the repo):
- `Dense.inter_open_nonempty` / `dense_iff_inter_open` produce membership in
  `U ∩ s` (**open set first**), not `s ∩ U` — got `.1`/`.2` backwards on
  first attempt; the type errors on the wrong projections made it obvious.
- `(a+1)/c = a/c + 1/c` isn't something bare `linarith` sees (different
  atoms syntactically) — `rw [add_div]` first, then `linarith` closes it.
