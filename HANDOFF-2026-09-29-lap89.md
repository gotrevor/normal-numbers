`VandeheyS7Quadratic` (S7-QD) lands the arithmetic. The run from state `s` on input `z` emits the CF
of `s.mob z`, so at a FIXED input the block average is the frequency of `w` in that CF (up to the
clock rate, which is `1` on both sides of the witness). Take

* `sqrtTwoSub = √2 − 1`: a **fixed point** of `gaussMap`, so every digit is `2`
  (`cfDigit_sqrtTwoSub`) — digit `1` has frequency `0`;
* `twoSqrtTwoSub = 2√2 − 2`: a `gaussMap`-**2-cycle** through `(√2−1)/2`, digits alternate `1,4`
  (`cfDigit_twoSqrtTwoSub_even/odd`) — digit `1` has frequency `1/2`;
* `shiftState : t ↦ 2/(t+2)`: rational entries, width `1/3` (`shiftState_width`), and
  `shiftState_mob_sqrtTwoSub : shiftState.mob sqrtTwoSub = twoSqrtTwoSub`.

So for `w = [1]`, `η ≤ 1/3`, the two states `refState` and `shiftState` have block averages `≈0` and
`≈1/2` at the SAME input point, for every `T`. Two distinct periodic orbits never merge; the two
values are in different `GL₂(ℤ)` cycles of `ℚ(√2)` (discriminants `8`, `32`). Time-averaging cannot
help, so this is not probe trap #2.

**The repair, and why it costs nothing.** The architecture only ever evaluates `BlockForget` at the
orbit points `Gᵐx` of a CF-normal `x` (see `exists_abs_slotCountFreq_sub_le`, step 2), and a
quadratic irrational is never CF-normal (eventually periodic digits omit some digit entirely).
