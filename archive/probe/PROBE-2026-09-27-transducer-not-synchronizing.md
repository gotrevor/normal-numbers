# The CF det-±D transducer is NOT synchronizing — and what the real crux is

**Verdict: the `Synchronizing` hypothesis of `VandeheyAut.exists_jointFreq_limit` is
UNSATISFIABLE for the transducer Theorem 1.1 needs.  Route corrected; the correction
identifies the crux exactly and supplies a new, hot-spot-free mechanism for it.**

Probes: `probes/cf_transducer_sync.py` (decides synchronizability — the integer state set
is finite, so this is decidable), `probes/cf_transducer_class.py` (isolates the invariant).

## The transducer, in our normalization

State = primitive integer matrix `M = [[p,q],[r,s]]`, `|det M| = D`, read as the Möbius
map `t ↦ (pt+q)/(rt+s)` on `t ∈ (0,1)`.  With `B_a = [[0,1],[1,a]]` (so `t = 1/(a+t')`
is `t = B_a t'`):

* **ingest** `a ≥ 1`: `M ↦ M · B_a`;
* **emit** `d ≥ 1`: `M ↦ B_d⁻¹ · M`, legal when `M((0,1)) ⊆ (1/(d+1), 1/d)`;
* **emit integer part** `n ≥ 1`: legal when `M((0,1)) ⊆ (n, n+1)` (fires only at the head);
* **reduced** = nothing emittable, i.e. `M((0,1)) ⊆ (0,1)` straddling some `1/d`.
* `δ(M,a) = reduce(M · B_a)`.

Reachable reduced state counts (digits `1..8`): `x↦2x` **80**, `x↦x/2` **77**,
`x↦(x+1)/2` **78**, `x↦3x` **223**.  Finite, as Vandehey's §2 says.

## The refutation

No synchronizing word up to length 20 for any of these.  The image of the full state set
under words stalls at size 3 (`D=2`) / 4 (`D=3`) and never shrinks further.  Pairwise
merge analysis (a DFA is synchronizing iff every pair merges): **1953 of 3160 pairs are
unmergeable** for `x↦2x`, 16151 of 24753 for `x↦3x`.

## The invariant, and why no input can destroy it

After a common input word `w` (matrix `W = B_{a₁}⋯B_{a_k}`, `det = ±1`) the two states are
`P M W` and `Q N W` with `P, Q` products of emission matrices `B_d⁻¹` (`det = ±1`).  They
agree projectively iff `N = λ (Q⁻¹P) M` with `Q⁻¹P ∈ GL₂(ℤ)` — i.e. iff the **row lattices
`ℤ²M` and `ℤ²N` agree up to scaling**.  `W` is invertible, so it can never change that.

Measured: mergeable ⟺ equal row-lattice class, with **0 mismatches** over 3160 pairs
(`D=2`) and 14878 pairs (`D=3`).  Class counts: `D=2` → **3**, `D=3` → **4**; i.e.
`|ℙ¹(ℤ/D)| = D+1`.  Example of the obstruction: `M=[[0,1],[2,2]]` has row lattice
`2ℤ×ℤ`, `N=[[0,2],[1,1]]` has `{(a,b) : a ≡ b mod 2}` — both index 2, different lattices,
so they never merge.

## The class factor IS the crux, named exactly

The class evolves by `c ↦ c · B_a`, which depends only on `a mod D` (visible in the
measured tables: for `D=3` digits `1,4` act alike, `2,5` alike, `3,6` alike), and each
`B_a ∈ GL₂(ℤ/D)` acts **bijectively** on `ℙ¹(ℤ/D)` — so the class component never forgets
its past and no word can collapse it.  So the transducer is an extension

> `state = (class ∈ ℙ¹(ℤ/D))  ×  (fiber, which IS synchronizable inside a class)`

and the joint (window, state) frequency needs the frequency of **(window = q and
class = c)**, i.e.

> **the crux:** along a CF-normal orbit, the `ℙ¹(ℤ/D)`-valued cocycle
> `c_i = c₀ · B_{a₁} ⋯ B_{a_i} mod D` equidistributes, jointly with digit windows.

That is precisely what Vandehey's §3 buys with the Pyatetskii-Shapiro/Moshchevitin–Shkredov
lemma — the step Airey–Mance refuted.  So the crux was never the analytic assembly; it is
this cocycle.  Note this is *not* a Wall-type situation: Wall's base-`b` carry automaton
**is** synchronizing, which is exactly why Wall is elementary and this is not.

## New mechanism for the crux — Cesàro-shift + Fourier, no hot-spot criterion

Let `G` be the finite group generated by the images of `B_a` in `PGL₂(ℤ/D)`, `χ` a
nontrivial irreducible unitary rep, `P_i = ρ(B_{a₁}⋯B_{a_i})`, and `f` the indicator of a
window word.  Target: `T_n = (1/n) Σ_{i<n} f(win_i) · χ(P_i) → 0`.

1. **Shift.** `(1/n) Σ_i f(win_{i+k}) χ(P_{i+k}) = T_n + O(k/n)`, and
   `χ(P_{i+k}) = χ(P_i) χ(Q_i^{(k)})` with `Q_i^{(k)} = B_{a_{i+1}}⋯B_{a_{i+k}}` a function
   of the **window at `i`** alone.
2. **Cesàro-average the shift over `k < K`**:
   `T_n ≈ (1/n) Σ_i χ(P_i) · R_i`, where
   `R_i = (1/K) Σ_{k<K} f(win_{i+k}) χ(Q_i^{(k)})` is a function of the length-`(K+|q|)`
   window at `i`.  Hence `|T_n| ≤ (1/n) Σ_i ‖R_i‖ + O(K/n)`.
3. **CF-normality** (`tendsto_window_mem_freq`, already proved in
   `VandeheyAutomaton.lean`) sends `(1/n) Σ_i ‖R_i‖ → 𝔼_γ‖R‖`.
4. **Cancellation in the random walk**: under `γ`, `𝔼‖R‖² = O(1/K) + (decay of the
   `χ`-Fourier coefficient of the digit walk)`, because the `χ(Q^{(k)})` for well-separated
   `k, k'` decorrelate (ψ-mixing, `philipp_psi_mixing_holds`) and `𝔼χ(Q^{(k)}) → 0` for
   nontrivial `χ` by aperiodicity of the walk on `G`.  So `𝔼‖R‖ → 0` in `K`.

Only CF-normality on fixed-length windows plus the repo's mixing stack are used — the same
inputs the rest of `VandeheyAutomaton.lean` already runs on.  No P-S criterion, no
tightness hypothesis, no ergodicity of the skew product, no Ryll-Nardzewski/VHS.
