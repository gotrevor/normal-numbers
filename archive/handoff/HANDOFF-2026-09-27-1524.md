## 🧠 Context to carry forward

The paper's §2 encoding lemma is a torus-Fourier argument: the uniform measure on
`({2a/b^s})_{b∈S}`, `0 ≤ a < lcm(S)^s`, annihilates every *fixed* nontrivial character
once `s` is large (the smallest supported base dominates), hence converges weakly to
Haar. That argument is **correct** — I checked it, including the shallow-resonance
caveat — but formalizing it in arbitrary dimension is expensive: weak convergence alone
does not give an interior-box hit, you additionally need a nonnegative product Fejér
kernel plus a per-coordinate Markov step (`∫_{outside} T dμ ≤ Σ_i 1/(4Hδ_i²) < 1`).
I costed that at ~1000+ lines and **abandoned it**.

Replacement (this is the session's actual mathematical advance): an elementary
constructive proof. Two facts collapse it —

1. *Free choice at one base.* With `frac b s a = {2a/b^s}`, the reachable values
   `{(2n mod b^s)/b^s}` form a grid of spacing `2/b^s`. Any window inside `[0,1]`
   longer than that is hit by an explicit residue offset `α < b^s`. The witness is
   `α = (n + b^s − A % b^s) % b^s` with `n = ⌊u·b^s/2⌋ + 1`. No characters, no CRT.
2. *Cheap interference.* That offset, being `< b₀^s`, moves a **larger** base `b > b₀`
   by only `2α/b^s < 2(b₀/b)^s ≤ 2θ^s`, `θ = b₀/(b₀+1) < 1`.

So: induct on `S.card`, **strip the smallest base**, solve the larger bases against
windows shrunk by `ε/2`, spend exactly that slack on one correction at the smallest
base. Pick `s` with `2θ^s < ε/2` — that single condition makes the grid fine enough
*and* the interference negligible. `2 ≤ a` is met by padding with `2·∏_{b∈S} b^s`
(periodicity lemma `frac_add_mul`).

The only property of the bases used is **distinctness** — that is precisely what gives
`b₀/b < 1`. No coprimality, no multiplicative independence. Dead end worth recording:
a *triangular* scheme (make each correction a multiple of `lcm` of the already-set
bases) is the obvious first idea and it **provably cannot work** — `{2,3,6}` defeats
every ordering, because `m mod 6^s` is a CRT function of `m mod 2^s` and `m mod 3^s`.
Processing smallest-*last* with a perturbation budget is what fixes it.
