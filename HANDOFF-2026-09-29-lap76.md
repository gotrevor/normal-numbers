## ⚠️ Three things refuted or corrected in kernel this lap

1. **`StateData` was vacuous** (`stateData_of_orbitWordBound`).  Pinning a witness to a TYPE pins
   nothing: `MobState` interpolates the single pair of points the coupling evaluates
   (`lowState (Gⁿy/Gⁿx)`, width `Gⁿy/Gⁿx`, distortion `1`).  A machine hypothesis has content only
   when its data is pinned as a FUNCTION of the input.
2. **`StrictMono N` was wrong** (S7-C3).  `clockIndex = findGreatest … m` silently assumes
   `N n ≥ n`, i.e. one output digit per input digit.  Transducers stall.  `clockIdx = sInf {n |
   m < N (n+1)}` needs no monotonicity for its two defining properties.
3. **`MobState` cannot emit** (S7-NE).  `readMap a ∘ u = t` forces `u.a = t.c − a·t.a`, and
   `emitWitness = [[1,1],[0,2]]` (image exactly `I₁`) needs `u.a = −1`.  It is not
   orientation-reversal that is missing — `readMap` reverses — it is a decreasing NUMERATOR.

## ✅ What `MapState` is, and why it is the right type

`0 ≤ b ≤ d`, `0 ≤ a+b ≤ c+d`, `0 < d`, `0 < c+d`: exactly "`mob` maps `[0,1]` into `[0,1]`", since
numerator and denominator are affine in `z`.  Closed under composition (`aux`/`aux_pos`: run the
endpoint conditions at `z = p/q`), and emission is then unconditional — `exists_emit` needs only
that both endpoint values lie in `[1/(a+1), 1/a]`.

## 🔑 The one idea the lap turned on

**Irrationality alone runs the machine.**  Not a width floor, not a distortion bound, not
equidistribution.  The image orbit point `zₙ` is irrational, so it is INTERIOR to its cylinder
(`exists_digit_of_irrational`); the input word contracts by `1/4` every two digits with no
continuants (`lipConst_readMap_comp`: `readMap a ∘ readMap b = [[1,b],[a,ab+1]]`, det `1`, minDen
`ab+1 ≥ 2`); so a stalling state eventually fits inside the cylinder and must emit.  Directive fact
(β) is precisely the statement that this would fail for a rational `1/k`.
