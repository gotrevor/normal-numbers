# The 82000 lane (2026-10-09)

Lean: `src/NormalNumbers/ZeroOneBases.lean`.  Search + tests: `experiments/zero-one-bases/` (`./test_joint.py`, 11 known-answer tests against brute force, Burrell–Yu's S(n) terms, OEIS A263684/A146025).

`A_b` = integers with only 0/1 digits in base b, about `X^(log 2/log b)` of them below X.

- **Invented, then found in print.**  Furstenberg intersection (Shmerkin–Wu) on `A₄ × A₅` gives `O(n^ε)`: this is Burrell–Yu Thm 1.2 (arXiv:1905.00832), recorded as `Literature.BurrellYuFourFive`.  It never uses base 3.  GMR (arXiv:2007.05480) Question 5.2 is the general finiteness form (dimension sum < 1 ⇒ finite intersection) and implies Erdős #406 too.
- **Kill: digit-count exponents alone.**  `threeNine_infinite`: `A₃ ∩ A₉ ⊇ A₉` is infinite though its exponent is −0.054.  A proof must use multiplicative independence.
- **The pair (4,5) carries the conjecture.**  Exponent −0.069.  Exact top-down search (base-4 digits from the top, exact "next 0/1 integer in base 5" prune) finds only `0, 1, 5, 16400, 16401, 16405, 82000, 82001, 82005` (OEIS A263684) through base-4 length 8339 (≈10⁵⁰²⁰), in 9 minutes on one core.  `zeroOneBases2to5_of_zeroOneFourFive`: that list being complete implies the 82000 conjecture.
- **The pair (3,4) is open the other way.**  Burrell–Yu ask whether `S(n) > 0` infinitely often.  Counts by base-4 length (1..55): 1 1 0 3 6 3 0 5 12 11 0 5 12 0 0 5 0 0 0 48 14 0 61 188 83 0 81 232 268 0 0 650 0 0 622 299 0 0 0 501 0 0 2655 602 0 6429 8990 7856 0 26187 17898 3744 0 40300 16395; lengths 56–60 are empty.  630 of 1039 solutions below 4³⁰ are primitive (not a digit-disjoint sum of smaller solutions), so the solution set is not generated by a few seeds.
- **Wall for (3,4) infinitude.**  Construction `N = 4ᵏ + r` with `r ∈ A₄` short: the top base-3 digits of 4ᵏ are a rotation by `k log₃ 4` (equidistributed along progressions), the bottom needs the shift `c = 4ᵏ mod 3ᵐ` to admit `r` with `c + r ∈ A₃ (mod 3ᵐ)`.  Good shifts are a positive proportion (the sumset `A₃(m) − A₄` has size product `3^{1.131m}` but low frequencies carry the Cantor gaps, so not "almost all").  Whether 4ᵏ's shift is good is decided by the *middle* base-3 digits of 4ᵏ: the same unknown as Erdős #406.  L¹ Fourier (Riesz products, masses 4/3, 1.207, 1.294 per digit) is far too weak with two digits.
