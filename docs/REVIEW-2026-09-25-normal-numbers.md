**25 September scale correction and AGP exception-avoidance candidate.** Lap20's `HANDOFF-2026-09-24-swing-c2-lap20.md:77-80` and source `SwingC2.lean:2957-2965` say `M=exp((log Y)^θ)` with `θ` bounded away from zero. ## Cross-branch fidelity audit: C3-MRT formal TT interface

I independently checked the live `nn-c3mrt` source after the parent review flagged it.  `C3MrtTTThm31.lean:90-93` defines `TTNonPretentious g X L := ∃ A>0, ∀ |t|≤(log X)^(1/125), A L≤ exp(ttPretentiousSum g X t)`.
