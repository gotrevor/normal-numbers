## The plan for item 4, fully worked out on paper (do NOT re-derive)
One layer per excluded length; layer `m` has period `Q m`, offset `off m`, arm `arm m`.
`stage n := blockSeq (multiG (Q n) (layerGads n)) (blockOf 2 (Q n) x) (Q n)` for a binary normal `x`.
1. **`stage_eq_of_ge`** — layer `i` covers `m` only if `m ≥ off i ≥ Q i / 2`, so for `n ≥ m`
   `stage n m = stage m m`; define `limSeq x m := stage x m m`.  Uses `blockSeq_multiG_eq_absGad`
   (both sides equal `absGad` at the *same* absolute base) and `blockSeq_multiG_eq_of_notMem`.
2. **`diffCount_stage_le`** — `hbig` gives `off m ≥ Q m/2`, so layer `m` has 0 bases below `M`
   when `Q m ≥ 2M` and `≤ 3M/Q m` otherwise; hence
   `diffCount limSeq (stage n) M ≤ 12·M·∑_{m>n} 1/Q m`, i.e. `c n = 0`,
   `η n = 12∑_{m>n}1/Q m → 0`.  Exactly the shape `tendsto_onesFreq_of_linear_diff` wants.
3. **`stage_law_at_arm`** — a gadget of arm `L` is separated ONLY by `(r,b) = (p+1, 0)`
   (for `b ≥ 1` the trace starts at `0 ≠ p+1`), so `k(r) ∈ {0,1}` and the defective residues are
   exactly `{p+1 : (p,L) ∈ gs}` — there are `Q n / Q m` of them.  With `winGf_coeff_eq`,
   `blockFreq(0) = ((Q n − Q n/Q m) + (Q n/Q m)·3/4)/(Q n·2^L) = (1 − 1/(4·Q m))/2^L`,
   **independent of `n`** and `< 1/2^L`.  That is the single `v` the transfer needs.
4. **Assembly.**  `L` not an arm ⇒ every stage abelian at `L` (`multi_isAbelianAt_of_notMem`) ⇒
   `limSeq` abelian.  `L = arm m` ⇒ every stage has `onesFreq → (1−1/(4 Q m))/2^L` at `j = 0` ⇒
   `limSeq` too ⇒ not abelian.  Then build the `LayerSys` for a given `S ∋ 1` by recursion:
   arms enumerate `Sᶜ ∩ {L ≥ 2}`, `Q (n+1) := Q n · (big enough that off+arm+1 < Q)`, offset from
   `exists_avoiding_offset` **translated by a multiple of `Q n`** (which preserves all the
   `mod Q m` conditions, `m ≤ n`) to enforce `hbig`.
