# Schmidt 1960 — pin note (read 2026-10-05, Theorem 1)

W. M. Schmidt, *On normal numbers*, Pacific J. Math. 10 (1960) 661-672.  PDF alongside
(gitignored), from msp.org.

- **Theorem 1.** A: if `r ~ s` (`r^p = s^q` for some `p, q ≥ 1`), normal to base `r` implies normal
  to base `s`.  B: if `r ≁ s`, the set of numbers normal to base `r` but not even simply normal to
  base `s` has the power of the continuum.
