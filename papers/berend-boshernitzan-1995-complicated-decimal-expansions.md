## Results used in the tower audit

Definition 3.1 calls `A subset N` an `M_g`-set when, for every irrational
`alpha` and every finite base-`g` word, some `m in A` makes that word
occur infinitely often in `m alpha`.

Remark 3.1 observes that for each fixed length `k`, an `M_g`-set supplies
one multiplier containing every length-`k` word infinitely often.  Theorem
3.1 characterizes such sets through dilations of infinite `g`-invariant
subsets of the circle.  Corollary 3.3 says removing any finite subset preserves
the `M_g` property, so no finite set solves the unrestricted all-word-length
problem.

C2 is only the fixed length-one problem.  The paper's impossibility for finite
full `M_g`-sets therefore does not rule out `{2,11}`; it clarifies the exact
truncation in which finite hitting sets can be novel.
