## ⚠️ Gotchas added this lap

- `Finset.range_subset` is `range n ⊆ s ↔ ∀ x < n, x ∈ s`; for `range a ⊆ range b` use
  **`Finset.range_subset_range`**.
- `Nat.findGreatest_spec` needs `(P := …) (m := 0)` given explicitly or it unifies `P` to `Eq _`.
- `unfold clockIndex` before any `omega` that must see a `findGreatest` fact.
- `div_le_div_of_nonneg_right` wants `0 ≤ c` in a slot where the natural term is `0 < c`; prefer
  `gcongr` with the numerator inequality pre-`have`d.
- `abs_add` is **not** the name here; the triangle inequality for `|x + y|` is `abs_add_le`
  (and `abs_sub` for `|x - y| ≤ |x| + |y|`).
- `gcongr` frequently closes the whole goal — always check for "No goals" before adding bullets.
- A `Prod` equality goal needs `simp only [Prod.mk.injEq]` before `constructor`.
- `if _ ∈ A then _ else _` on a `Set ℝ` needs `Decidable`; write `{_t : ℝ | …}` instead.
