## Gotchas (this lap)

- **`List.getElem_ofFn` + `congr 1` on `Fin`-coerced indices is fragile**:
  after `rw [List.getElem_ofFn, ...]`, the goal has terms like
  `↑⟨i, proof⟩ : ℕ` (anonymous-constructor `Fin` coercions). `congr 1;
  omega` sometimes closes this directly (elaborator-dependent — the linter
  even flagged a `simp only [Fin.val_mk]` as "unused" once), but rebuilding
  the SAME unchanged file later can make `omega` fail on the un-reduced
  coercion atoms. **Always keep `simp only [Fin.val_mk]` before `congr 1`**
  in this pattern, even if the linter calls it unused — the alternative is
  nondeterministic build breakage. (This is a new, not-yet-in-corpus
  gotcha — worth writing up if it recurs.)
- **`Nat.add_mul_div_right`/`Nat.add_mul_mod_self_right` need `x + y*z`
  form with the SPECIFIC variable you're isolating as `x` and the
  known/multiple factor grouped as `y*z` ending in the divisor/modulus**:
  e.g. to simplify `(k*b^L+V)/b^L`, commute FIRST to `V+k*b^L` (matching
  `x+y*z` with `x=V,y=k,z=b^L`) — `Nat.add_mul_div_left` (divisor as the
  FIRST factor `y`) is the wrong lemma when your product has the divisor
  LAST; don't guess, check which factor position matches your term via
  `#check` before reaching for `_left` vs `_right`.
- `Finset.card_nbij'` (mathlib, non-dependent bijection cardinality) needs
  goal hypotheses in `Set.MapsTo`/`Set.LeftInvOn`/`Set.RightInvOn` form —
  after `intro`/`rintro`, `simp only [Finset.coe_filter, Finset.mem_range,
  Set.mem_setOf_eq]` (or `Finset.coe_product, Finset.mem_coe,
  Finset.mem_range, Set.mem_prod` for products) is needed to unfold Set-coe
  membership into plain `Finset.mem`-style facts; plain `Finset.mem_filter`
  won't match since the ambient goal is stated over `↑s : Set α`, not `s :
  Finset α`. `Set.mem_setOf_eq` is deprecated (→ `Set.mem_ofPred_eq`) but
  still works — cosmetic warning only, not fixed this lap.
