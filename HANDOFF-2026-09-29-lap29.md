## 🧠 The four ideas worth carrying

1. **The crux is now about WORDS, not intervals.**  `OrbitACBound` quantified over arbitrary
   subintervals, and nothing in the transducer layer speaks about intervals — it computes word
   frequencies.  `cellSet w T = cfCylinder w ∩ {y | T ≤ cfDigit y |w|}` bridges them: `T = 1` is the
   cylinder, `T ≥ 2` is the tail cell "word `w`, then a digit ≥ T".  Cylinders ALONE cannot work (an
   interval is a countable union of them, and truncating leaves a remainder whose visit frequency is
   exactly what is being bounded — circular); with tail cells, `(0,1)` has a FINITE partition into
   short intervals at every resolution.  `orbitACBound_of_orbitCellBound` + `cellCover_inv_log_two`
   ⟹ the crux is exactly `OrbitCellBound q r₀ C`.
2. **Tail cells need no geometry — only invariance.**  The cheap step in `cellCover_inv_log_two`:
   only the depth-`n` cylinders must be short (to be trapped in a `4/2ⁿ`-neighbourhood).  All
   level-`m` tail cells together sit inside `(gaussMapᵐ)⁻¹(0,1/T)`, whose γ-mass is `≤ 1/(T log 2)`
   by `gaussMeasure_preimage_iterate`.  So `n` levels cost only `n/(T log 2)`: pick `2ⁿ > 64/(δ log 2)`
   then `T > 8n/(δ log 2)`.  No Möbius-branch estimates anywhere.
3. **Merging costs nothing for an infinite state set.**  `hdist_runWord_le`: the contraction factor
   `(3−2√2)^⌊|w|/2⌋` is a property of the INPUT word, and a state is nonexpansive, so the bound is
   uniform over the (infinite) state set.  Still only a DIAMETER bound, never a LOCATION bound — it
   is an input to a distributional argument, never a substitute for one.
4. **Lagrange's theorem is not needed for bounded partial quotients.**  `A b² + B b d + C d²` is a
   nonzero integer, so `≥ 1`; it equals `d²(b/d − z)(A(b/d+z)+B)`; and `|z − b/d| ≤ t/d²` by
   unimodularity of the continuant matrix.  Hence `Gⁿz ≥ 1/(2|A|+|B|)` for every `n`.  Three
   ingredients, all by induction on the word.
