## Lap 135 addendum — the single-`n` joint sample, quantified

`Grouped.grouped_union_card_le`: atoms partitioned into `G` groups, each group sharing one sample
point; the read set below `L` is `≤ G · |𝓕| · (L m H dmax / (2 dmin^w) + H m)` with `w` the
smallest group size.  Derived by applying `union_card_le` on each group's atom subtype and
summing.  `G = 1` recovers the implemented sampler; `G = H` is total release.

**The finding**: confinement survives iff `dmin^w ≳ G H`, i.e. iff every group has size
`w ≳ 2 log H / log dmin` (at `G = H/w`).  The single-`n` joint sample is therefore *not*
essential — the sample may be broken into `H/w` independent blocks — but the blocks must be that
large.  The honest residue of the item is a sampler with groups below that size.

All three of R's "still open" items have now moved: (E) narrowed to one probabilistic inequality
(lap 133), matrix-dependence removed (lap 134), joint-sampling quantified (lap 135).

## Lap 137 addendum — the anti-concentration deduction behind (E), proved

New module `src/NormalNumbers/G4RowVariance.lean`.

* `sampleAvg_sq_lower` — the general deduction: for a weighted row `R(n) = Σ_i c_i X_i(n)`,
  `avg R² ≥ v·Σ c_i² − ε·(Σ|c_i|)²`, given per-term non-degeneracy (`avg X_i² ≥ v`) and
  near-orthogonality (`|avg X_i X_j| ≤ ε` for `i ≠ j`).  Proof: expand the square into the double
  sum, average termwise (`avg_double_sum`), keep the diagonal exactly and bound each off-diagonal
  by `−ε|c_i||c_j|`.
* `rowVariance_half` — the packaged reduction: if `ε·ratio ≤ v/2` where `ratio` bounds
  `(Σ|c|)²/Σc²`, then `avg R² ≥ (v/2)·Σc²`, which is exactly the shape
  `Budget.RoughRowVarianceLower` asks for.

**What this changes.**  (E)'s residue is no longer "an analytic estimate".  It is two explicitly
named arithmetic inputs about `ω` along a CRT progression, with everything between them and the
verdict proved:
1. per-term non-degeneracy `v` — the rough-prime fluctuation at one shifted argument has sample
   second moment bounded below;
2. near-orthogonality `ε` at distinct shifts, needed at level `ε ≤ v/(2·ratio)` with
   `ratio ≈ 2^K` for the schedule's `c_{α,j} = A_{να} 4^{-j}`.

Neither is a statement about the sampler's shape; both are about `ω` on a progression.

| case | contribution |
